# Dependency and asset record

Application code for the desktop aquarium is new in this repository. The solution and initial project files were bootstrapped with .NET SDK 10.0.202 templates, then adapted to the approved plan.

- .NET/WPF/Windows Forms: Microsoft .NET desktop framework; https://github.com/dotnet/wpf and https://github.com/dotnet/winforms (MIT). G0 was source-only. The later local G4 candidate bundles .NET Core/Windows Desktop 10.0.10; this does not change the shared machine runtime.
- MSTest 4.0.2: development-only dependency from the installed SDK template; resolved versions are recorded in the test project's `packages.lock.json`. https://github.com/microsoft/testfx (MIT).
- The feeder PNG/ICO and the fish atlas are original prototype assets generated by `scripts/Generate-Assets.py` (Python standard library, no runtime asset downloads). The atlas has three color palettes and four tail poses; this is not a species collection. The resident icon now uses the bundled feeder ICO. Final artwork remains subject to user review.
- G0 markers remain explicitly labelled probe-only drawing primitives. No third-party fish/desktop-pet artwork is incorporated into the live feeding prototype.
- The Devpost Learn Skill Pack is development curriculum installed separately, not an implemented aquarium feature.

A project publication license and final asset provenance must be reviewed before public distribution. No license has been selected on the participant's behalf.
