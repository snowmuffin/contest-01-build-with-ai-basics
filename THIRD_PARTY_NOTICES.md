# Dependency and asset record

Application code for the desktop aquarium is new in this repository. The solution and initial project files were bootstrapped with .NET SDK 10.0.202 templates, then adapted to the approved plan.

- .NET/WPF/Windows Forms: Microsoft .NET desktop framework; https://github.com/dotnet/wpf and https://github.com/dotnet/winforms (MIT). G0 was source-only. The later local G4 candidate bundles .NET Core/Windows Desktop 10.0.10; this does not change the shared machine runtime.
- MSTest 4.0.2: development-only dependency from the installed SDK template; resolved versions are recorded in the test project's `packages.lock.json`. https://github.com/microsoft/testfx (MIT).
- The feeder PNG/ICO remain deterministic project assets generated by scripts/Generate-Assets.py. The currently bundled fish atlas was recorded as participant-directed AI-generated artwork; its extraction quality is now under renewed review. Generate-Assets.py validates its dimensions without overwriting it. The resident icon uses the bundled feeder ICO. No asset downloads occur at runtime.
- Independent fish-frame candidate (2026-09-27): the participant supplied `ChatGPT Image Sep 27, 2026, 04_41_16 PM.png` directly for this task. The unchanged source copy, SHA-256 and origin limitations are recorded in `assets/fish/source/provenance.json`. `scripts/Extract-FishFrames.py` produces 32 native-resolution RGBA frames with preserved source RGB and explicit binary masks; it does not generate replacement artwork. These candidates await participant review and are not bundled in the app. No third-party artwork was fetched for this pass; final publication licensing remains the participant's decision.
- Pillow 11.0.0: development-only image extraction/review helper dependency, already installed; local package metadata identifies its license as MIT-CMU. Project: https://github.com/python-pillow/Pillow . It is not included in the aquarium runtime or self-contained package.
- G0 markers remain explicitly labelled probe-only drawing primitives. No third-party fish/desktop-pet artwork is incorporated into the live feeding prototype.
- The Devpost Learn Skill Pack is development curriculum installed separately, not an implemented aquarium feature.

A project publication license and final asset provenance must be reviewed before public distribution. No license has been selected on the participant's behalf.
